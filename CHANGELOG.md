# VHERE Demo 0.8.0

October 29, 2026

- First signed evaluation release with the separate `com.vhere.demo` identity.
- Preserves the older development app and its records by installing alongside it.
- Prefills the public HTTPS service URL and certificate pin; token remains private.
- Includes offline evaluation license, bundled-library notices and map attribution.
- Uses the previously validated road-aware motion/turn display without changing numerical maps, models or acceptance conditions.
- Documents Collegiate coverage, final output availability/error, complete recorded-route comparisons and measured request timing.
- Device setup checks cover non-debuggable installation, native UI and real public-endpoint HTTPS health. Independent outdoor field accuracy remains pending.

This is a non-commercial research demo. Low-speed/joint display limitations,
schematic lane geometry and server/network availability limits remain documented.
