# VHERE Release Assets

The signed application and verification files are available from the
[0.8.0-demo Release](https://github.com/YangRiverJiang/vhere-demo/releases/tag/v0.8.0-demo).

- `VHERE-demo-0.8.0-release.apk`: signed, non-debuggable Android application.
- `SHA256SUMS.txt`: artifact checksums.
- `SIGNING-CERTIFICATE.txt`: APK publisher certificate, distinct from the TLS pin.
- `release-manifest.json`: version, source/map identities and validation scope.
- `VHERE-demo-0.8.0-docs.zip`: complete documentation repository snapshot.

No access token or signing private key is included. This is an evaluation release;
new-drive accuracy and public-cellular performance remain to be measured.
