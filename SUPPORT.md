# VHERE Demo Support

Use the [issue tracker](https://github.com/YangRiverJiang/vhere-demo/issues) for setup, navigation and release problems.
For a first report, include version, phone/Android version, travel direction,
approximate occurrence time, task/session ID and a redacted screenshot. Describe
whether the problem concerns camera readiness, connection, final position, lane
uncertainty, turning or reacquisition.

Do not attach tokens, private keys, connection exports, precise private locations,
original photographs or full session ZIPs to an issue. Ask for a private transfer
channel when needed. Data-deletion requests can identify the task/session first.

See the [manual](docs/MANUAL.md), [service details](docs/SERVICE.md) and
[field-test guide](docs/FIELD-TEST.md) before a drive. Preserve original records
and recording-error messages; a smooth screenshot alone does not establish accuracy.
